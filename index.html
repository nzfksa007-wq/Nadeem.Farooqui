My consulting methodology

DMAIC gives each improvement project five steps, from agreeing on the problem to sustaining the gains.

Agree on the problem

Set a clear scope, identify the people affected and agree on what success looks like.

Output Problem statement and target KPI

Establish the baseline

Collect reliable data and map the current process so the starting point can be measured.

Output Baseline and process map

Find the root causes

Use the data to separate recurring drivers from symptoms and confirm where the process breaks down.

Output Verified causes and priorities

Test a practical change

Pilot the change, compare the result with the baseline and refine it before rolling it out.

Output Tested improvement and rollout plan

Keep the gains in place

Assign ownership, update standard work and monitor the KPI for early signs that performance is slipping.

Output Control plan and review cadence
